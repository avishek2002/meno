# Agent harness craft - pack provenance

Working effectively with an agentic coding harness: what the harness actually assembles
around the model, how to keep its context lean, when a workflow deserves a reusable
skill, how to bolt on deterministic guardrails, and how to route work to the cheapest
capable model tier. Structure and anchor sources only, per the pack model: lesson bodies
generate at adoption against the adopter's own contract.

Concepts are harness-agnostic where possible; anchor sources are the public Claude Code
and Claude API documentation plus Anthropic engineering posts, because that harness
documents these mechanisms most thoroughly. An adopter using a different agentic tool
maps the same concepts onto their tool's equivalents.

Maintainers listed above are advisory reviewers for amendments, not owners with veto.
