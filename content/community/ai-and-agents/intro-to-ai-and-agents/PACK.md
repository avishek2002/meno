# Intro to AI and agents - pack provenance

First principles for a developer meeting large language models (LLMs) as a user and
builder, not as a researcher. Five modules walk from what a model actually is (tokens,
training, next-token prediction) through working with one (prompting, context windows,
sampling, structured output), its failure modes (hallucination, knowledge cutoffs, jagged
capability), the step from model to agent (tool use, the agent loop, planning), and the
ecosystem (APIs, open-weight vs hosted models, where agents fit in real workflows).

Structure and anchor sources only, per the pack model: lesson bodies generate at adoption
against the adopter's own contract. The notes/ directory carries shared reference notes
several lessons would otherwise each explain from scratch.

Maintainers listed above are advisory reviewers for amendments, not owners with veto.
