# Contributing to Meno - pack provenance

Hand-authored onboarding pack for the repository itself, built with the draft-a-pack
recipe. Two streams: building Meno (the repo's shape and rules, then landing a change)
and authoring community content (what a pack is, then the pack gate). Every module is
exercise-driven: the notes frame why a rule exists and point at the file that owns it;
the docs themselves stay the only place procedure lives. Lesson bodies generate at
adoption against the adopter's own contract, per the pack model.

Maintainers listed above are advisory reviewers for amendments, not owners with veto.
